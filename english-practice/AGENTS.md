# 英语学习视频项目约定

制作、修改或继续本目录的英语学习视频前，先阅读 [英语学习视频制作规范.md](英语学习视频制作规范.md)，并以用户已确认的第一段复杂句中英对照版为参考。

- 后续章节默认采用：原视频原声＋带标点英文字幕，片尾选当前章复杂句，英文分句紧接中文，重点词及对应中文加粗，并提供语境词义。
- 片尾选句数量与页数根据本章内容和排版需要确定，不固定为3页；默认每页5秒，总时长为实际页数×5秒，不为凑数编造句子。章节原片长度依据实际完整句边界，不固定为第一章长度。
- 片尾静音；不要加跟读、原声重播、配音、替换练习、倒计时、进度条或音乐。
- 使用HyperFrames；保持720p、浅奶油背景、深绿文字、已确认的字体与排版层级。新中文子集须覆盖本章所有字形。
- 用户后续明确指令优先于上述默认值。复用已确认偏好，避免重复询问相同问题；按当前HyperFrames技能要求完成实际预览及最终导出确认。
- 用户只要求规范或模板时，不自动开始制作其他章节。不得主动push远程。
