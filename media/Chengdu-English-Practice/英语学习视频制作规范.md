# 英语学习视频制作规范

版本：1.2 · 2026-10-06  
状态：以用户已确认的「第一段复杂句中英对照版」为标准。后续章节默认沿用本规范；用户后续明确提出的修改优先。

## 1. 成片结构

**当前章节原视频（原声＋带标点英文字幕）→ 本章节复杂句中英对照片尾。**

面向中文母语的英语初学者及观看视频的粉丝。原片用于理解真实语境，片尾用于看懂复杂句和重点词。片尾使用 HyperFrames 制作。

## 2. 视频来源与章节切分

- 使用已下载的原视频作为素材，目标画质为720p。已有素材够用时直接复用。
- 以已确定的章节/段落为基础切分。检查实际声音，切点落在完整句末，避免截断单词、句子或下一章的开头。
- 必要时微调计划切点，记录实际起止时间；相邻章节同步调整，避免漏掉内容或重复播放同一句。
- 保留章节内画面、说话顺序和原声。不额外变速、裁剪画幅、添加装饰或音乐。
- 第一章计划结束于22秒，实际为完整收尾调整到22.64秒。这是本章实例，后续章节使用各自实际时长。

## 3. 原片英文字幕

- 优先使用可获得的英文字幕。无论平台是否标为人工字幕，都需复核内容与讲话是否一致。
- 补齐句首大写、专有名词大写和句末标点，按语义断句；保留博主原话、缩写、口语、省略和重复。
- 识别错误经原声核实后纠正；听不清的内容先核对，不凭上下文编造。
- 字幕按实际讲话同步，使用原声或词级时间校准，不机械均分时间。
- 每次最多两行，避免短语被拆散、过长一行或上一句迟迟不消失。阅读速度过快时调整字幕分组。
- 英文字幕直接烧录进视频，让粉丝无需开启字幕即可观看。原片默认仅显示英文字幕，中文解析集中在片尾。
- 延续已确认的白字黑色细描边、下方居中样式，避开画面边缘；字号以720p下可读为准。

## 4. 片尾复杂句筛选

- 只选**当前章节实际说过的句子**，优先选择有学习价值的较复杂句：转折、原因、条件、从句、句中省略或常用口语表达。
- 根据本章实际内容，挑选值得解析的复杂句，数量不固定，按视频出现的顺序排列；不以简单寒暄句替代复杂句解析。
- 保留所选原句全部内容，可按语义分成小块展示，不删掉难的部分，不把原句改成新例句。
- 不凑固定句数或页数，也不编造内容。句子数量取决于本章的学习价值与内容；长句可拆成连续页面，不必强制一句一页。

## 5. 中英对照与加粗规则

通常每页处理一句复杂句；较长句子可拆成连续页面。页面内容按以下顺序排列：

1. 顶部：简短的句子主题及页码，例如「复杂句解析 · 转折：更重要的是」「01 / 03」。
2. 中部：英文分句一行或自然换行，其下立即放对应中文；再展示下一组英文和中文。
3. 底部：2–3个重点单词或短语及本句中的中文含义。
4. 最下方：必要时补一句简短的句子说明，解释连接词、代词指代或省略；无需说明时省略。

具体要求：

- **英文重点词加粗，对应的中文词语也加粗。** 普通文字与重点文字有清楚的字重差别，不能整句话都加粗。
- 每个中文分句只对应紧上方的英文分句，避免把整段中文集中放在所有英文之后。
- 分句合起来必须组成完整原句；英文与中文可采用各自自然的语序，不强行逐词直译。
- 中文准确、自然、适合初学者，必要时用语境解释隐含意思，不加入原话没有的事实。
- 释义优先采用该句语境：例如 missed this city 指行程中没来这座城市；epic 在本片口语中为「超棒的」；coming up 为「接下来、即将到来」。
- 不堆砌无关词义、长篇语法知识或大量生词。

## 6. 片尾时长与声音

- 页数根据本章选句及排版需要确定，不固定为3页。默认每页5秒，片尾时长＝实际页数×5秒；完整成片时长＝本章原片时长＋片尾实际时长。
- 片尾为静音阅读页。**不加入跟读、原声重播、配音、替换练习、倒计时、进度条或背景音乐。**
- 每页只保留约0.3秒的轻微淡入，随后保持文字稳定；不使用打字机、逐词跳动或花哨转场。
- 长句放不下时，先合理分块，必要时拆为连续页面并相应延长片尾；不靠缩小文字硬塞。记录变更后的页数与总时长。
- 不沿用旧版「四张9秒原声跟读卡片」。该方案已被本规范替代。

## 7. 已确认的视觉样式

| 项目 | 默认值 |
|---|---|
| 画布 | 1280 × 720，16:9横屏 |
| 背景 | 浅奶油色 #F4F2E6 |
| 主文字 | 深绿色 #163E32 |
| 中文与辅助文字 | #416457 |
| 分隔线 | #CFD6C6 |
| 英文字体 | Montserrat，普通500字重，重点800字重 |
| 中文字体 | Noto Sans SC，普通400字重，重点800字重 |
| 英文原句 | 39px，行高1.3 |
| 中文翻译 | 28px，行高1.5 |
| 重点词释义 | 24px，行高1.35 |
| 简短句子说明 | 20–22px |
| 内容区 | 左右约128px边距，宽约1024px；顶部标题，中央对照，底部释义 |
| 视觉处理 | 平面排版、细分隔线，无阴影、装饰面板或渐变 |

内容密度变化时可调整间距和词条位置，但保留字体层级、颜色及中英紧邻关系。关键文字保持在10%安全边距内；底部辅助说明至少保留5%边距。每页都要检查完整文字是否越界或重叠。

字体作为本地素材嵌入，保证渲染与预览一致。使用中文字体子集时，必须重新包含当前章的全部汉字和标点，不能直接复用第一章子集导致缺字。

## 8. 制作与交付流程

1. 读取本规范及参考成片，按默认要求执行，不重复询问已经确定的720p、版式或是否跟读等偏好。
2. 整理本章带标点英文字幕，校准时间，确定完整句切点。
3. 选出复杂句，写好分句中英对照、加粗位置、语境释义和必要句子说明。
4. 用 HyperFrames 制作本章片尾，接在原片之后；各章保持独立成片和项目文件。
5. 检查原片字幕以及每张片尾页面，完成字体、排版、对比度和播放验证。
6. 按当前 HyperFrames 技能要求，先展示实际完整预览，再取得最终导出确认。无需重开版式设计或重复征求同样偏好。
7. 导出720p MP4，验证成片后交付视频链接和同名学习文案；保留可编辑项目与字幕文件，方便后续修改。

文件建议命名：`章节编号-章节名称-Complex-Sentences.mp4`，对应文案使用同名 `.md`。字幕 `.srt` 的时间从本章0秒开始，只覆盖原片阶段。

## 9. 导出与验收

默认MP4、H.264视频、AAC音频、30fps；保持原素材宽高比。参考版使用CRF22，清晰度优先，文件大小不设硬性目标。

交付前逐项确认：

- [ ] 章节开头和结尾没有截断原句；实际时长已记录。
- [ ] 原片英文字幕有标点，内容及时间与讲话一致，每次不超过两行。
- [ ] 每个片尾句子来自当前章节，分句连起来没有缺词或改写。
- [ ] 每段英文下方立即有对应中文，重点词及中文对应词已加粗。
- [ ] 词义与语境相符，中文无错字，字体无缺字。
- [ ] 所有片尾页面逐张查看，文字清晰，没有越界、重叠或异常切换。
- [ ] 原片声音保留；片尾没有原声重播、跟读、额外配音或音乐。
- [ ] HyperFrames完整检查通过；导出的MP4能完整解码，包含正确画面和音轨。
- [ ] 导出成片与已确认预览一致，旧版不覆盖，最新版标识清楚。
